# 통합 시연

**AI 판단 → 장치 반응 → DB 기록**이 한 번에 이어지는 것을 보여준다.

## 1. 준비

| 확인 | 방법 |
|---|---|
| Jetson 접속 | VS Code Remote-SSH (`jetson` USB 또는 `jetson-wifi`) |
| 다른 프로그램 종료 | `pkill -INT -f rail_face; pkill -INT -f convey_vision` |
| 웹캠 동작 | 실행 후 몇 초 안에 `[green] 얼굴 없음 -> 컨베이어 작동` 출력 |
| 대시보드 | 같은 Wi-Fi: `http://<Jetson IP>:5080` · 인터넷: `conveyor_dashboard/start_tunnel.sh`가 출력한 주소 (보기는 로그인 없이, 종료·DB 버튼만 `.env`의 `DASHBOARD_PASSWORD`) |
| DB 연동 | 대시보드 오른쪽 위 "DB 연동 켜짐" |

```bash
cd ~/Dokkab
conveyor_dashboard/.venv/bin/python conveyor_dashboard/launcher.py   # 종료 후 웹에서 다시 시작 가능
```

## 2. 시연 시나리오

| 단계 | 사람 행동 | AI 판단 (터미널) | 장치 반응 | DB·대시보드 |
|---|---|---|---|---|
| 1 | 카메라 앞을 비운다 | `[green] 얼굴 없음 -> 컨베이어 작동` | 벨트 작동, LED 꺼짐 | 신호등 초록. NORMAL "얼굴 미검출 · 작업자 없음, 정상 작동" |
| 2 | 1~2m 거리로 다가온다 | `[yellow] 1xx.xcm -> 컨베이어 작동` | **벨트 계속 작동**, 노랑 LED | 신호등 노랑. WARNING "… 접근 경고(200cm 이하), 벨트 작동 유지" |
| 3 | 50cm 안으로 다가온다 | `[red] 4x.xcm -> 컨베이어 정지` | **벨트 정지**, 빨강 LED | 신호등 빨강. DANGER, 정지 이유 "작업자 위험 접근(50cm 이하)" |
| 4 | 다시 멀어진다 | 1초 뒤 `[yellow]` 또는 `[green]` | 벨트 다시 작동 | 신호등 노랑 또는 초록. WARNING / NORMAL 기록 |
| 5 | 대시보드 "DB 연동" 버튼을 끈다 | (판단은 계속) | 벨트·LED 정상 동작 | 새 기록이 생기지 않음 |
| 6 | 다시 켠다 | | | 기록 재개 |
| 7 | "대시보드 종료" 버튼 | `종료했습니다.` | 벨트 정지, LED 꺼짐 | NORMAL "프로그램 종료로 벨트 모터를 정지했습니다." |
| 8 | 새로고침 → [다시 시작] + 비밀번호 | 프로그램 다시 실행 | 벨트 다시 작동 | 대시보드 다시 표시 |

### 보여줄 포인트

- **단계 2**: 경고에서는 멈추지 않고 알리기만 한다. 불필요한 정지로 생산이 끊기는 것을 막는다.
- **단계 3**: 위험 거리에서는 즉시 멈춘다. 정지 시각과 이유가 DB에 남는다.
- **단계 4**: 1초 안정화 덕분에 얼굴 검출이 잠깐 끊겨도 벨트가 덜컥거리지 않는다.
- **단계 7**: 어떤 방법으로 꺼도 벨트가 멈춘다(안전 쪽 종료).

## 4. 시연 체크리스트

- [ ] 촬영 전: 대시보드에서 카메라·신호등·로그가 스크롤 없이 한 화면에 보이는지 (필요하면 Chrome `F11` 전체 화면)
- [ ] 단계 1: 벨트 작동, LED 꺼짐, 신호등 초록
- [ ] 단계 2: 노랑 LED, 벨트 **작동**, 신호등 노랑
- [ ] 단계 3: 빨강 LED, 벨트 **정지**, 신호등 빨강, 대시보드에 정지 이유 표시
- [ ] 단계 4: 1초 뒤 벨트 재작동
- [ ] 단계 5~6: DB 연동 끄기/켜기
- [ ] 단계 7: 종료 버튼 → 벨트 정지
- [ ] 단계 8: 새로고침 → [다시 시작] → 벨트·영상 다시 켜짐
- [ ] 대시보드 로그 최신순, 날짜·시간·상태·내용 표시
- [ ] 로그 기간 검색: [오늘]·[1개월] 버튼, 달력으로 시작~끝 날짜 지정 후 [검색]
- [ ] 다른 기기(휴대폰 등)에서 인터넷 주소로 접속 → 로그인 없이 영상·로그 확인 → DB 버튼을 누르면 비밀번호를 묻는지 확인

## 5. 시연 중 문제 대응

| 증상 | 대응 |
|---|---|
| 상태 줄이 안 나옴 | 웹캠 USB 다시 꽂기 |
| `Device or resource busy` | 남은 프로그램 종료 후 재실행 |
| 대시보드가 안 열림 | 같은 Wi-Fi인지 확인. 인터넷 주소는 `start_tunnel.sh`를 다시 켜면 새 주소가 나온다 |
| 버튼을 누르면 비밀번호 창이 뜸 | `.env`의 `DASHBOARD_PASSWORD` 입력 (PC에서는 `conveyor_dashboard/jetson_env.txt`에서 확인). 새로고침 전까지는 다시 묻지 않는다 |
| 종료 후 화면이 "연결할 수 없음" | 몇 초 뒤 새로고침하면 [다시 시작] 화면이 나온다 (`launcher.py`로 실행한 경우) |
| 얼굴이 검출 안 됨 | 카메라를 정면으로 보기, 조명 확인 |
