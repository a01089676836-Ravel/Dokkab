# 프로젝트 계획서 (수정본)

- **과정명**: 온디바이스 AI 기반 산업용 소프트웨어 개발 1기
- **담당강사**: 유영식
- **최초 작성일**: 2026-09-30
- **수정일**: 2026-10-01

> **수정 사항 요약**
> - 온도·초음파 센서와 서보모터는 사용하지 않기로 결정했다. 입력은 카메라 하나로 한다.
> - 출력 장치는 빨강·노랑 LED(처음에는 파랑, 2026-10-06 노랑으로 교체)와 **L9110S 드라이버로 구동하는 DC 모터(컨베이어 벨트)**로 바꿨다.
> - 경고(노랑) 상태에서는 노랑 LED로 알리기만 하고 벨트는 계속 돌린다. **위험(빨강) 상태에서만 벨트를 정지**한다.
> - 로그 저장소는 SQLite/CSV 대신 **Aiven MySQL**을 쓴다. Jetson 안의 SQLite는 전송 대기함으로만 쓴다.
> - 카메라 인덱스는 Jetson에 연결한 USB 웹캠 기준 **0번**으로 확정했다.

## 1. 프로젝트 개요

- **프로젝트명**: 비전 AI 기반 컨베이어 작업자 접근 감지 및 안전 알림 시스템
- **팀장**: 전종현
- **담당파트**: 시스템 아키텍처, FSM·대시보드 구현 및 통합

| 이름 | 담당 내용 |
|---|---|
| 전종현 | 전체 아키텍처, 상태 판단(FSM), 대시보드, 데이터 기록 및 통합 |
| 송태원 | 회로 구성 및 Jetson 보드 연결 |
| 장호영 | 비전 AI 작업자 검출 및 거리 측정 |

## 2. 문제 정의

작업자가 컨베이어 장비에 가까워지는 상황을 제때 알아차리지 못하면 충돌이나 끼임 사고가 발생할 수 있다. 카메라로 작업자의 얼굴을 검출하고 장비와의 거리를 추정해, 접근 시 경고를 표시하고 위험 거리에서는 벨트를 정지하는 시제품을 구현한다.

## 3. 구현 목표

1. 카메라 영상에 OpenCV YuNet 얼굴 검출을 적용하고, 얼굴 상자 높이로 작업자 거리를 추정한다.
2. 상태 판단이 정상·경고·위험(·오류) 상태를 구분한다. 얼굴 검출이 잠깐 끊겨 상태가 깜빡이지 않도록 안정화한다.
3. 출력 장치는 빨강·노랑 LED와 DC 모터(컨베이어 벨트)만 사용한다. 경고는 노랑 LED로 알리고 벨트는 계속 돌린다. 위험은 빨간 LED를 켜고 벨트를 정지한다.
4. 상태 전이와 오류, 장비 정지 시각·사유를 Aiven MySQL에 기록한다. HTML 대시보드는 최신 로그가 위에 오도록 표시한다.

## 4. 사용 기술 및 개발 환경

- **하드웨어**: NVIDIA Jetson Orin Nano, USB 웹캠, 브레드보드 회로, 빨강·노랑 LED, L9110S 모터 드라이버, DC 모터(컨베이어 벨트)
- **개발 환경**: Windows PC(VS Code Remote-SSH) + Jetson 보드 시험 환경
- **개발 도구**: Python 3.10, OpenCV FaceDetectorYN(YuNet), Jetson.GPIO, Flask, PyMySQL, HTML 대시보드
- **주요 구성**: YuNet ONNX 얼굴 검출 → 거리 추정 → 상태 판단 → LED·벨트 제어 → Aiven MySQL 기록 → HTML 대시보드
- **YuNet 설정값**: 모델 `face_detection_yunet_2023mar.onnx`, 카메라 인덱스 0, score threshold 0.8, NMS threshold 0.3. 모델 파일이 없거나 10KB 미만이면 다시 내려받는다.
- **거리 기준**: 추정거리(cm) = 13000 ÷ 얼굴 상자 높이(px). 50cm 이하 위험, 200cm 이하 경고.
- **제어 원칙**: 안전 상태 전이는 상태 판단 로직이 결정한다. HTML 대시보드는 화면 표시와 기록 조회만 하고 장치를 직접 제어하지 않는다.

### HTML 대시보드 화면 구성

| 위치 | 표시 내용 |
|---|---|
| 왼쪽 | 카메라 화면(얼굴 상자·거리 표시)과 현재 상태 |
| 오른쪽 | 운전 중 발생한 로그 목록. 날짜·시간·상태·내용·정지 이유를 기록하며 최신 로그가 맨 위 |

## 5. 개발 계획 (수정)

- **1주차**: 요구사항과 데이터 형식을 확정한다. 센서·서보를 범위에서 제외하고 카메라 기반 구조로 정리한다.
- **2주차**: YuNet 코드로 카메라 입력과 얼굴 검출을 단독 시험한다. 카메라 인덱스·해상도·임계값을 확인하고 거리 추정식을 정한다.
- **3주차**: 비전·상태 판단·대시보드·DB를 연결한다. 정상·경고·위험·오류 흐름을 로그로 확인한다.
- **4주차**: 배선과 핀 설정을 확인한 뒤 LED·벨트 출력을 시험한다. 상태 깜빡임을 안정화하고, 통합 로그를 대조해 시연 자료와 제한사항을 정리한다.
