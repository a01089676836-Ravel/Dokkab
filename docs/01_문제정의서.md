# 문제정의서

비전 AI 기반 컨베이어 작업자 접근 감지 및 안전 알림 시스템

## 1. 현장 문제

컨베이어 벨트는 계속 움직이는 장비다. 작업자가 정비나 물품 정리를 위해 가까이 다가갔을 때 벨트가 그대로 돌고 있으면 끼임·충돌 사고가 날 수 있다. 작업자는 작업에 집중하느라 장비와의 거리를 놓치기 쉽고, 관리자도 모든 순간을 지켜볼 수 없다.

필요한 것은 다음 세 가지다.

1. 작업자가 다가오는 것을 **자동으로 감지**한다.
2. 가까워지면 **먼저 경고**하고, 위험 거리에서는 **장비를 멈춘다**.
3. 언제, 왜 경고하고 멈췄는지 **기록을 남겨** 나중에 확인할 수 있게 한다.

## 2. 사용자

| 사용자 | 필요한 것 |
|---|---|
| 현장 작업자 | 장비에 너무 가까이 갔을 때 바로 알 수 있는 신호(LED), 위험 거리에서 자동 정지 |
| 현장 관리자 | 실시간 카메라 화면과 현재 상태, 경고·정지 기록(날짜·시간·사유) 조회 |
| 유지보수 담당자 | 오류(카메라 끊김, 프로그램 종료 등) 발생 시각과 원인 기록 |

## 3. 입력과 출력

### 입력

| 입력 | 내용 |
|---|---|
| USB 웹캠 영상 | 640×480, Jetson Orin Nano에 연결한 카메라 0번 |

> 계획 단계의 온도·초음파 센서는 최종 범위에서 제외했다. 입력은 카메라 하나다.

### 처리

1. **얼굴 검출**: OpenCV YuNet(`face_detection_yunet_2023mar.onnx`)으로 프레임마다 얼굴 상자를 찾는다.
2. **거리 추정**: 추정거리(cm) = 13000 ÷ 얼굴 상자 높이(px). 얼굴이 여러 개면 가장 가까운 값을 쓴다.
3. **상태 판단**: 거리로 상태를 정하고, 깜빡임을 거른다(더 위험한 쪽은 즉시, 안전한 쪽은 1초 유지 후 적용).

### 출력

| 상태 | 조건 | 벨트(DC 모터) | LED | 기록 |
|---|---|---|---|---|
| 정상 (green) | 얼굴 없음 또는 200cm 초과 | 작동 | 꺼짐 | 상태 변경 시 기록 |
| 경고 (yellow) | 50cm 초과 ~ 200cm 이하 | **작동 유지** | 노랑 | 상태 변경 시 기록 |
| 위험 (red) | 50cm 이하 | **정지** | 빨강 | 정지 시각·사유 기록 |

추가 출력:

- **HTML 대시보드**: 왼쪽 카메라 화면과 현재 상태 신호등(빨강 위험·정지 / 노랑 경고·작동 / 초록 정상·작동), 오른쪽 이벤트 기록(최신이 위). 세 가지가 스크롤 없이 한 화면에 보인다. 기록은 기간(오늘·1주·1개월·3개월 버튼, 또는 달력으로 시작~끝 날짜 지정)으로 검색한다. 같은 Wi-Fi 주소나 인터넷 주소로 다른 기기에서도 로그인 없이 볼 수 있다(종료·DB 버튼만 비밀번호 필요)
- **Aiven MySQL**: 모든 상태 변경과 정지·종료 이벤트 저장

## 4. 성공 기준

| 번호 | 기준 | 확인 방법 |
|---|---|---|
| S1 | 작업자가 50cm 이내로 오면 벨트가 정지한다 | 시연에서 빨강 상태 → 벨트 정지 확인, DB에 DANGER·정지 기록 |
| S2 | 50~200cm에서는 노랑 LED가 켜지고 벨트는 계속 돈다 | 시연에서 노랑 상태 → 노랑 LED, 벨트 작동 확인 |
| S3 | 작업자가 떠나면 벨트가 다시 돈다 | 정상 상태 1초 유지 후 벨트 작동 |
| S4 | 얼굴 검출이 잠깐 끊겨도 상태가 깜빡이지 않는다 | DB 로그에서 1초 미만 상태 반전 비율이 줄었는지 비교 |
| S5 | 모든 상태 변경·정지·종료가 날짜·시간과 함께 DB에 남는다 | 대시보드 로그와 DB 조회 결과 대조 |
| S6 | 대시보드에서 카메라 화면과 최신 기록을 실시간으로 본다 | 브라우저에서 영상과 로그 갱신 확인 |
| S7 | 프로그램이 어떤 방식으로 끝나도 벨트가 멈춘다 | Ctrl+C, q 키, 대시보드 종료 버튼 각각으로 종료 시 벨트 정지 |

## 5. 범위 밖

- 얼굴이 보이지 않는 작업자(뒤돌아선 사람, 마스크·안전모로 가린 얼굴)의 검출
- 정확한 실제 거리 측정(현재는 얼굴 크기 기반 추정)
- 온도·초음파 센서, 서보모터 (계획 단계에서 제외)
- 최적화 모델(TensorRT)을 메인 프로그램에 적용하는 것 (변환과 전후 벤치마크는 수행: 10 최적화 모델, 11 벤치마크 결과)
